# In-person complaint operating guide

Authorised Reception/office delegates, Principal or Director record the original source, requester identity as supplied, contact, time, receiving Staff, category, exact original statement, signed-paper reference where applicable and privacy acknowledgment. An admission number alone never verifies identity.

The original statement is immutable. A transcription correction is a new message/event; the scanned signed form remains a private attachment. Parent-visible summaries and internal handling notes are separate. Print acknowledgments display an opaque support reference and safe summary, not internal IDs or notes.
