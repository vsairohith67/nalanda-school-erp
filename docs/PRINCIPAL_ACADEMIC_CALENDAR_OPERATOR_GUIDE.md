# Principal Academic Calendar Operator Guide

Use **Academic calendar** to create an academic-year operational version, add dated classifications, inspect totals and impact, and then move it through review, approval and publication. Review all attendance and examination conflicts. If posted attendance is affected, supply the explicit reconciliation reason. Use replacement for a published correction; do not attempt to edit published rows.

Use the event editor for bounded title, description, dates/times, approved-text venue, audience and exact active class/section scope. Examination entries reference the existing current published timetable. Preview the resolved audience before review/publication. Replace or withdraw with a reason and inspect history/audit evidence after each transition.

Emergency closure requires `MANAGE_EMERGENCY_CLOSURE`, exact dates and a reason. Calendar publication does not activate email, SMS or WhatsApp, does not publish to the public website and does not change posted attendance.
