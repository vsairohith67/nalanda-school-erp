# Academic Reporting Operator Guide

1. Choose the academic year, report family and exact exam/class/section/subject
   filters. The selector lists current issued versions only.
2. Read source-readiness and Class IX/X boundary warnings. For a comparative
   report, select at least two examinations and an explicit compatibility rule.
3. Use class average/highest only when an approved reference is available.
4. Generate the report. Open source/version evidence before relying on the
   result. An incompatibility remains separated with a reason.
5. Export only through the authenticated CSV, colour PDF or monochrome PDF
   actions. Export history records the role, format, mode and time without a raw
   actor identifier.
6. If an issued source changes, the former run displays a stale-source warning.
   Generate a governed superseding run; never edit old output.

An empty completion report can indicate locked results without issued report
versions. It is an evidence gap, not proof that an examination or Student result
does not exist. Do not upload these reports to public, board or government
systems under this phase.
