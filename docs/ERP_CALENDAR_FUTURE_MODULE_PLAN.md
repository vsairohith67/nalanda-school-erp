# ERP Calendar Future Module Plan

This is a planning note only. No calendar module is currently built.

## Future idea

Create a simple internal ERP calendar for management, Director, Super Admin, Principal, and staff.

Possible uses:

- school-wide reminders
- to-do tasks
- academic holidays
- exam schedules
- alerts
- overdue task follow-up

## Recommended order

Start with an internal ERP calendar first. It should handle school-wide tasks and academic dates inside Nalanda Fee Control before connecting to outside calendar services.

Consider Google Calendar sync later only after the internal ERP calendar is stable, permission-safe, and useful for daily school work.

## Scope guard

Do not build Parent portal, Teacher dashboard, Principal dashboard, attendance, messaging automation, or cloud calendar sync as part of the first calendar step unless a later prompt explicitly opens that scope.
