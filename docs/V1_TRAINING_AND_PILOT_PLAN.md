# V1 Training and Pilot Plan

Training uses synthetic data in a private environment. Suggested order: Super Admin/Director governance; Admin/Computer Operator records; Accountant fee and reconciliation; Principal/Teacher academic scope; Parent linked-child portal; support and safe-exit operators.

A pilot requires named owners, a small authorized cohort, daily reconciliation, support escalation, backup/rollback coverage and explicit stop conditions. No pilot may create real users, import real records, send live messages, collect live payments or issue real reports until those actions receive separate authorization.
