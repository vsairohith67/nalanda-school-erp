# Communication Provider Activation Gates

`COMMUNICATION_DELIVERY_FOUNDATION_1A_CLEARED` is software clearance only. It leaves provider selection, live certification and operational activation incomplete.

## Selection gate (1B)

Refresh current official evidence for Indian Email, SMS, WhatsApp Business and native push options. Compare eligibility, pricing, India sender/domain/template registration, data processing, support, receipts, webhook security, limits and lock-in. Do not choose from repository memory and do not buy or configure anything.

## Per-provider certification gate (1C)

Certify exactly one approved channel/provider at a time in private staging. Require approved contract/privacy review, secret storage and rotation, sender/domain registration, official signature verification, rate/cost policy, real-provider sandbox evidence, monitoring, rollback, support owner and explicit activation approval. Keep unrelated channel flags off.

## Native push gate (1B)

Require private HTTPS staging, actual Android/iOS devices, approved FCM/APNs credentials, user permission UX, token rotation/revocation, environment binding, app/version policy, lock-screen privacy, background/foreground/tap/deep-link tests and store/distribution readiness. Simulator-only evidence is insufficient.

## Operational entry gates

Private repository/staging, approved real-data onboarding, current contact provenance/verification, consent policy approval, real-user activation, training, pilot plan, incident/rollback process, budgets and owner sign-off remain separate. No fixed live-channel order is selected in 1A.
