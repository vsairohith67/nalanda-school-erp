# Real-Data Onboarding Preparation 1A Clearance

## Verdict contract

Terminal repository release status: `REAL_DATA_ONBOARDING_PREPARATION_1A_CLEARED` only when the exact feature head containing this evidence passes focused, security, no-write, provider-compatibility and full-regression CI, is normally merged, and the annotated release tag resolves to that merge. External SHA/run/tag/tracker evidence is recorded by the release operator and must not be inferred from this file alone.

## Cleared software scope

- Empty source inventory and authority framework.
- Immutable-source chain-of-custody and deterministic package manifest.
- 89 service-level mappings across academic structure, Students, Guardians, Staff, lifecycle, finance, history, documents, optional operations and privacy gates.
- Conservative generic CSV/XLSX admission with checksums, paths, encoding/delimiter/header/container/resource limits.
- Deterministic synthetic packages at 120 Students, 160 Guardians and 30 Staff plus nine domain files; adversarial rows are synthetic.
- No-write dry-run classifications, duplicate candidates, integer-paise reconciliation and eight fixed formula-safe reports.
- Eight-wave dependency plan, approval/separation-of-duties, rollback/correction, privacy/retention and post-import runbooks.
- Vendor-neutral source export request and generated future execution prompt.

## Explicitly not cleared

Real files were not requested, received, inspected, transformed, validated or imported. Schoolknot export, source authority/conflict resolution, legal/privacy approval, private staging, provider/DNS/deployment, real users, production migration/cutover, OCR and biometric data remain unapproved.

The repository was PUBLIC at task start, so actual onboarding is blocked. `real-data-imports` remains production OFF at 0%. The preparation engine imports no Prisma client, opens no database and performs no network request.

## Required terminal evidence

- Dedicated clean feature worktree based on current authorised main.
- Operational SQLite baseline/final size, SHA-256 and sidecars match.
- Mapping/schema/fixture/report focused tests pass on SQLite and PostgreSQL-labelled/provider gates.
- Security review has zero unresolved Critical/High and zero privacy/data-integrity Medium.
- Existing IMPORT-1A, Student, Guardian, Staff, finance, Schoolknot, backup/restore, Security Resilience, Portable Staging and Synthetic Pilot regressions pass.
- Full tests, typecheck, build, routes, lifecycle, backup and Git safety pass; intentional qpdf skips are disclosed.
- Exact feature SHA has terminal-success CI; PR head matches; normal merge and annotated tag are proven.
- Existing canonical Notion/Asana/Canvs records are updated after terminal evidence and read back, or connector unavailability is reported accurately.

## Boundary statement

Preparation clearance means tooling and decision contracts are ready for later private controlled use. It never means the school is migration-ready or that operational activation is authorised.
