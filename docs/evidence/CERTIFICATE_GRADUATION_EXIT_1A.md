Governed replacement drafts link to original history. Cancellation preserves it. Newly enabled reusable PDFs cover all five certificate types; existing functions remain available with new flags OFF.
- Use designated GRADUATION miscellaneous-income item, exact year rates, independent charge approval and the existing receipt transaction. Missing configuration differs from zero or an explicit approved waiver. Charge/request/Student/year links and unique receipt binding prevent second collections on retry, reprint or failed PDF generation. TC eligibility, Student lifecycle, Board packages and other sales are unchanged.
- Certificate-specific XLSX validates approved Graduation requests: exact admission/name/year/class, no source overwrite or new Student, immutable upload/mapping/target hashes and separate selected-row approval. One bounded row at a time supports interrupted retries, successful-row retention and explicit row errors/results. ZIP admission, a time/memory bounded parser worker and existing onboarding OPC checks reject formulas, macros, external links, unsafe structures and over-limit workbooks.
- Shared bounded PDF capacity produces private saved A4 documents. Georgia Bold must be locally licensed and available; no font file is committed. Draft watermark and footer appear on every page. QR is a 256-bit opaque URN, with no claimed live endpoint. Authenticated, rate-limited verification returns a minimal status/type/year allowlist. Unknown/expired/void/superseded references cannot authenticate.
- Add three durable tables and two nullable certificate linkage fields in matched new SQLite/PostgreSQL migrations. Backup v46 contains original PDF bytes, provenance, template/reissue/void, charge and batch idempotency state; v45 remains accepted. Conflicting target ownership/content is refused. Restored unapproved Graduation templates require fresh preparation before independent activation.
