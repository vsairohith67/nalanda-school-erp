# Support resolution and reopening policy

Resolution requires a category, requester-visible summary, internal action summary, resolving actor/time, expected version and optional safe corrective-workflow reference. It never mutates finance, attendance, marks, report cards, Student records, accounts or payroll directly. Earlier resolutions remain versioned.

The requester supplies a bounded reopen reason. Reopened requests return to the governed queue; five repeated reopens trigger Staff review rather than silent discard. Safeguarding/leadership-only closures require restricted review. Satisfaction is one optional response per resolution version and cannot rank employees.
