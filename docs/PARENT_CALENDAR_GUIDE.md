# Parent Calendar Guide

Open **Calendar** in an active Parent role context. Choose a linked child when more than one is available. The month, agenda and upcoming views show published school-wide entries, the selected child's exact class/section events, approved holidays/non-working days and relevant current published examination references.

Replaced items are labelled changed. Drafts, Staff/leadership content, unrelated classes, internal notes and attendance diagnostics are never shown. Switching child refreshes the server-held scope; a removed link or stale tab is denied. Use the authenticated print view for the same authorised content only.
