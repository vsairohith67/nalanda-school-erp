# Pilot Quick Reference Sheets

## Accountant: fee collection

Confirm role/environment → select governed Student/family → verify dues/allocation → enter Cash or manual digital evidence → submit once → verify authoritative receipt → print/reprint. On uncertainty after network failure, search before retry. Offline draft ≠ receipt.

## Accountant: end-of-day

Opening Cash + Cash fees + Cash misc income − paid Cash expenses = expected closing. Compare actual; difference must be zero paise. Cross-check Daily Collection, receipt sequence, expenses, misc income and Cash Book. Freeze and escalate any gap.

## Teacher: attendance and daily work

Confirm assigned cohort → mark roster → submit → Principal lock. Do not edit a locked day or another class. Then complete assigned timetable, classwork/homework, own Staff tasks and Parent Meetings. Ordinary Teacher marks-write is prohibited.

## Marks operator

Open `/marks/governed` → choose only assigned sheet → enter/validate → submit → request correction if needed. No moderation, calculation, lock, report issue or IAM.

## Principal approvals

Review evidence and version → confirm separate authority → approve/reject with reason → verify immutable history. Never approve through an ambiguous role or bypass Academic Integrity.

## Parent portal

Confirm selected child after every switch. Only issued reports and active linked-child data are valid. Wrong/unpublished handles should show private denial. Report any cross-child flash immediately.

## Super Admin incident response

Name commander → revoke affected session/device/account → preserve evidence → scope audit → freeze sensitive mutation if needed → assign owner/update time. Do not paste secrets or claim provider-edge controls are active.

## Offline Sync

Only Current Year Fee, Expense and Misc Income drafts. Unlock trusted device → create encrypted draft → queued/pending state → reconnect → one server-authoritative result. Conflict/rejection remains unresolved until reviewed. Old Due unavailable; draft not official.
