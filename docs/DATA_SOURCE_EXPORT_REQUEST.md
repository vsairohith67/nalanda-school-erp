# Data Source Export Request Template

Do not send automatically. Fill only after owner/vendor authority and a secure return channel exist.

Please provide vendor-supported exports for the owner-approved scope: Student records, Guardian relationships, Staff, academic-year enrolments, class/section/subject masters, fee structures, dues/opening balances, Payment/receipt history, attendance, marks/report history, and a documents/media inventory.

For each export, provide the data dictionary, field definitions/types/null meanings/status codes, stable IDs and relationship keys, exact school/branch/filter/year/date scope, export timestamp/time zone, row/distinct-ID/control totals, format/encoding/delimiter/date/decimal rules, SHA-256, and lawful data-return/contract restriction confirmation.

Preferred format is UTF-8 CSV. XLSX must contain no macros/formulas/external links. PDFs are archive evidence, not structured records. Do not send credentials, direct database access, biometric templates, undocumented archives or data outside the approved scope.

Return files only through the separately agreed private channel. Do not send them through GitHub, public links, ordinary chat, Notion, Asana or Canvs.
