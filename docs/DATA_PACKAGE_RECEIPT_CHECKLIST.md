# Data Package Receipt Checklist

- [ ] Recipient, source custodian, owner and transfer authority verified.
- [ ] Package received through approved private channel into isolated storage.
- [ ] Original filename/size/SHA-256/export and receipt timestamps recorded.
- [ ] Original bytes made read-only; working copy created separately.
- [ ] Manifest file list, domains/years, confidentiality and authority declared.
- [ ] Malware result recorded; executables/macros/archives/password protection refused.
- [ ] Package/file checksums and sizes match.
- [ ] Retention, supersession and disposal decisions opened.
- [ ] Receipt status recorded without source content in external trackers.
