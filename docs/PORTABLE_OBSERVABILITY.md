# Portable observability

Public liveness states only process life. Public readiness returns bounded ready/unavailable without dependency names. Token-protected internal health reports safe database/migration, Valkey and object codes. Token-protected metrics use fixed aggregate names without identities, keys, sessions, SQL, secrets or free-form labels.

Structured logs are bounded JSON with fixed event code, level, timestamp, deployment/replica identifiers and allowlisted safe fields. Proxy logs remain private and retained by policy. Provider adapters map these interfaces without changing semantics.
