# Teacher Calendar Guide

Open **Calendar** in an active Teacher context. The view includes published school-wide entries, authorised Staff entries, exact actively assigned class/section events and current published examination references. Unrelated classes are excluded even when the account holds a broad calendar permission.

A Teacher who also has Parent access must switch to Parent context before choosing a child. Child context never carries into Teacher context. Teachers can propose events only if explicitly granted `PROPOSE_SCHOOL_CALENDAR_EVENT`; teaching a class never grants publication authority.
