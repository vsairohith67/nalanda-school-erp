# Staff Payslip Request Guide

## Requesting records

Open **My Payslip Requests** only in Staff/Teacher context. Parent context has no payslip navigation or data. Select one or more available months, choose a plain-language purpose, optionally add a required-by date and submit. Choose **Other** only with a brief explanation.

Only governed record months appear. A missing month may be before joining, in the future, unavailable, unknown or awaiting management review. Contact authorised management; do not submit salary values through the request explanation.

The timeline shows review, external preparation, protected upload, issue, rejection, cancellation and replacement. A request may be cancelled before preparation where policy permits; cancellation remains audited.

## Opening an issued document

The issued file is **Password-protected, editing-restricted and tamper-evident**. Download it from the authenticated portal. Then choose **Reveal opening password** and re-enter the current account password. The opening password is shown only in the temporary dialog and clears when the dialog closes or after its timeout.

Never send the PDF and opening password together. Do not place the password in email, messaging, notes, screenshots or support tickets. If a version is replaced, download the active version; the former version is no longer available to ordinary Staff.

Disabled/suspended accounts and ended Staff access fail closed. Post-exit retrieval is a governed management process subject to the approved retention policy; it is not a public-link or email workaround.
