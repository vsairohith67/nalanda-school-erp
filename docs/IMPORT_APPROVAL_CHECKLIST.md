# Import Approval Checklist

Use the empty [machine-friendly template](../templates/onboarding/approval-checklist.md). Approval requires exact package/mapping/wave/report hashes, named separation-of-duties actors, zero unresolved blockers, approved sensitive-field/retention decisions, resolved duplicates/references, accepted finance reconciliation, private-staging backup/restore/rollback evidence and expected counts/totals.

Approval is invalid if repository/staging/privacy/source state changes. It does not activate users or authorise production cutover.
