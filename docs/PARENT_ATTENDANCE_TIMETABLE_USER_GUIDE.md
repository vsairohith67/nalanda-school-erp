# Parent Attendance and Examination Timetable User Guide

Switch to the **Parent** role context. If more than one child is linked, choose the child in the existing child selector; the role and child controls are intentionally separate.

**Attendance** shows official posted records for the selected month. Each row distinguishes Present, Absent, Late, Half day and Excused. A date with no official record is not treated as absent or as a holiday. Counts are authoritative; percentage and working-day totals are not shown because the school has not approved those calculation policies.

**Examination Timetable** shows only the current published timetable for the child’s active class and section. It includes approved paper/date/time/reporting/venue information. “Updated published timetable” means the school replaced an earlier version. Draft and withdrawn timetables are never shown.

Use the print view only from an authenticated session and collect the paper promptly. If a link or role has changed, refresh and select the current context. An unavailable message does not confirm whether another Student record exists; contact the school through its established channel when help is required.
