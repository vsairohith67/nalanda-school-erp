# Academic Calendar Attendance-Impact Policy

An informational event has no attendance effect. Only the current published operational calendar supplies a working-day basis for new attendance activity. When an attendance session is submitted or locked, the service stores the relevant calendar version/day key and classification snapshot; it does not recalculate or rewrite earlier rows.

A replacement that changes a date with posted attendance must display the date, former and proposed classification, attendance-session count and a reconciliation warning. Publication requires an impact reason and appends evidence. Reconciliation, if authorised later, is a separate explicit operation. Historical locked report-card and issued publication records retain the basis that existed when calculated.
