# Report-Card Template Versioned Maintenance Policy

**Applies to:** approved Classes I-X `NALANDA_LEGACY_REFINED` colour and monochrome templates  
**Effective gate:** `REPORT_PRINT_ACCEPTANCE_CLEARED`  
**KG boundary:** KG/LKG/UKG remains a separate, default-off V1.5 foundation

## Version contract

1. An approved template version is immutable. Issued report snapshots retain their exact template, scheme, grade scale, calculation snapshot, signature configuration and publication version.
2. Every future edit starts as a new inactive draft template version. Editing an active or issued version in place is prohibited.
3. Activation requires an authorised preview and explicit approval. The previously approved version remains available as the rollback target.
4. Colour and monochrome variants advance together when geometry, content or calculations change. A mode-specific visual correction may remain isolated only when parity tests prove that page structure is unchanged.
5. Template availability never activates KG. The existing `kg-report-cards-v1-5` policy remains default-off until a separately authorised V1.5 acceptance phase.

## QA level

- Visual-only changes require focused rendering, A4, clipping, minimum-font, colour/monochrome parity, privacy and physical-risk checks proportional to the affected pages.
- Calculation, examination-scheme, component, weighting, grade-scale, rank, attendance-basis or cohort-statistic changes require the complete examination/reporting invariant suite and a new frozen snapshot contract.
- Changes affecting print geometry, patterns, signing space or minimum text size require a new physical specimen and acceptance before activation.

## Rollback and evidence

- Rollback reactivates the prior approved version; it never rewrites issued reports.
- Draft, approval, activation, replacement and rollback events remain versioned and auditable.
- Evidence uses synthetic data only. Restricted historical sources, real Student/Parent identities, marks, photographs and generated private reports must not be committed or uploaded.
- Release metadata records the approved template version and retains the previous approved template as the known-good rollback reference.
