# Post-Import Validation Checklist

- [ ] Exact batch/package/mapping/wave and actor/approval references match.
- [ ] Created/updated/linked/skipped/rejected counts match the approved dry run.
- [ ] Academic years, classes, sections and subjects resolve without duplicates.
- [ ] Student/Guardian/Staff identifiers and sampled links match approved evidence.
- [ ] Lifecycle effective dates/states match; no progression was inferred.
- [ ] Opening dues, credits, discounts, refunds, Payments, receipts and control totals reconcile in paise.
- [ ] Historical attendance/marks use only approved structured sources.
- [ ] Documents/media remain within approved inventory/storage/consent/retention scope.
- [ ] No sensitive field outside its explicit approval was imported.
- [ ] No active Parent/Staff account, notification or real-user access was created implicitly.
- [ ] Audit/lineage, idempotency and rollback class are complete.
- [ ] Source bytes/hash are unchanged and temporary working copies follow retention decisions.
- [ ] Backup/restore evidence remains valid.
- [ ] Owner accepts the wave or rollback/compensation begins.

Acceptance of one private-staging wave does not authorise the next wave, real-user activation or production cutover.
