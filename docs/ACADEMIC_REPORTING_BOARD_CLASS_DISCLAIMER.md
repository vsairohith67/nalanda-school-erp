# Class IX/X Reporting Disclaimer

Class IX/X reporting is internal academic evidence based on locked school
results and issued report-card versions. Revision and preboard comparisons may
support subject-wise review, but they are not an official board submission,
board eligibility determination, certification, predicted board mark or claim
of statutory compliance.

The disclaimer is embedded in every Class IX/X report summary and shown in the
selector before generation. It is retained in CSV/PDF output and immutable run
history.
