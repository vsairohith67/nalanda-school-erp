# Principal Examination Timetable Operator Guide

Open **Examinations > Examination Timetables** in an authorised Principal or leadership context.

1. Choose an existing active examination and exact class/section scope.
2. Create a draft, or clone the current published version when making a correction.
3. Complete every listed active paper with date, start and end time. Add reporting time, venue and Parent instructions only when approved.
4. Save, inspect the conflict summary and preview the Parent-facing projection.
5. Resolve every missing-paper, invalid-time, inactive-scope or overlap finding.
6. Mark the exact version ready, then publish with a meaningful reason.
7. For a published correction, publish the cloned replacement with a separate replacement reason. Never edit a published row.
8. Withdraw only when the timetable must disappear from Parent access; the history remains.

If the editor reports that the version changed, reload before acting. Do not retry with an old expected version. A Teacher assignment is not publication authority. This phase sends no SMS, email or WhatsApp message; communicate through a separately approved process if operationally required.
