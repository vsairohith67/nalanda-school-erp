# Provider adapter contract

An adapter supplies OCI compute; PostgreSQL 17 with pooled runtime/direct migrator identities; authenticated TLS Valkey; private S3-compatible storage; external secrets; private edge/WAF/access; DNS/TLS; off-host backup/object replication; scheduler; monitoring; budget/support; and DPA/legal approval.

It preserves command, health, metrics, object, backup, migration-lock, flags and native contracts. It may not patch authorization, enable features, import real data, publish an image or create public access to bypass limits.

Stop if ownership, region, budget, private access, DNS authority, TLS, backup durability, support or DPA/legal approval is missing.
