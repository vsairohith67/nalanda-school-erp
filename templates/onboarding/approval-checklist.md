# Import package approval checklist

- [ ] Source custodian and data owner are named.
- [ ] Original source bytes are immutable, hashed and stored separately from the normalized working copy.
- [ ] Provenance, authority, confidentiality and retention decisions are approved.
- [ ] Mapping version and dry-run package hash match.
- [ ] Every duplicate/conflict and sensitive-field decision is recorded.
- [ ] Financial control totals are `MATCH` or an approved `EXPLAINED_DIFFERENCE`; no unexplained difference remains.
- [ ] Private-staging backup, restore and rollback rehearsal passed.
- [ ] Technical approval and final owner approval are recorded.
- [ ] Real users remain inactive and production cutover remains separately blocked.

This empty template does not authorise import.
